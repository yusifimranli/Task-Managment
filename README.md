# Task Manager

Bu layihə React istifadə edilərək hazırlanmış Task Manager tətbiqidir.

## Features

- Login və Register
- Form validation
- Global state management
- Task əlavə etmək
- Taskları göstərmək
- Task edit etmək
- Task silmək
- Optimistic UI
- Error Boundary
- Responsive dashboard dizaynı

## Technologies

- React
- React Router
- Context API
- useReducer
- Tailwind CSS
- JSON Server
- JavaScript
